# Study System (Chang 10th — must-use template for every chapter)

## Opening spread (every Ch 1-25)
- Outline: list sections, e.g. 1.1-1.9
- Student Interactive Activity: kitchen chemistry / demo / estimate before reading
- A Look Ahead: where chapter leads (e.g. Ch1 measurement -> Ch3 stoichiometry -> Ch5 gases)

## In-chapter (every section)
- Marginal Notes: definitions, pitfalls (Co vs CO, mass vs weight, accuracy vs precision)
- Worked Example > Strategy > Solution > Check > Practice Exercise
  - Strategy: identify given/desired, pick equation
  - Solution: dimensional analysis, units cancel
  - Check: sign, magnitude, ball-park estimate
  - Practice Exercise: 1 variant with answer in appendix
- Review of Concepts: 2-3 quick checks
- Key Equations: boxed, e.g. d=m/V, C=(F-32)*5/9, PV=nRT, q=msDT, pH=-log[H+], E=E0-RT/nF lnQ

## End-chapter
- Summary of Facts and Concepts
- Key Words: substance/mixture, mole, molarity, enthalpy, entropy, etc.
- Questions and Problems: Review Questions > Problems > Additional Problems > Special Problems
  - Review = conceptual, Problems = section-mapped, Additional = mixed, Special = PhD/challenge

## Media (every chapter)
- Animations: e.g. Maxwell distribution, Le Chatelier, galvanic cell
- Media Player: lecture clips
- ARIS: adaptive homework (sig figs, balancing, ICE, Nernst)
- Quantum Tutors: step-wise problem coaching
- Presentation Center: figures/tables slides (Table 1.2 SI, Fig 2.10 periodic, Fig 5.11 STP)
- Test Bank: item pool per section

All 25 chapters implement this template in `docs/CH01-25-FULL.md` and `docs/chapters/`.
